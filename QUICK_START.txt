## 🎨 Customization Quick Tips

### Change Text
Edit `index.html` and find elements with:
```html
data-en="English version" data-hu="Magyar verzió"
```

### Change Colors
Edit `css/style.css` variables at the top:
```css
--primary-color: #1a1a2e;      /* Main color */
--highlight-color: #e94560;    /* Pink accent */
```

### Update Team Names
In `index.html`, find the Contact section:
```html
<ul class="team-list">
    <li>Barkóczi Alexandra</li>
    <li>Kuvik Ádám</li>
    <li>Bercsényi Tamás</li>
</ul>
```

### Update Email
Find this line in `index.html`:
```html
<a href="mailto:contact@qt-health.com" class="contact-link">contact@qt-health.com</a>
```
