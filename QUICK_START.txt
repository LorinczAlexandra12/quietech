## 🎨 Customization Quick Tips

### Change Text
Edit `index.html` and find elements with:
```html
data-en="English version" data-hu="Magyar verzió"
```

### Change Colors
Edit `css/style.css` variables at the top:
```css
--primary-color: #1a1a2e;      /* Main color */
--highlight-color: #e94560;    /* Pink accent */
```

### Update Team Names
In `index.html`, find the Contact section:
```html
<ul class="team-list">
    <li>Barkóczi Alexandra</li>
    <li>Kuvik Ádám</li>
    <li>Bercsényi Tamás</li>
</ul>
```

### Update Email
Find this line in `index.html`:
```html
<a href="mailto:contact@qt-health.com" class="contact-link">contact@qt-health.com</a>
```

## ❓ Common Questions

**Q: Can I see it without internet?**
A: The page can be opened locally, but the Brevo form requires internet access.

**Q: How do I change the default language?**
A: Change the default language in `js/script.js` and the initial content in `index.html`.

**Q: Can I add images?**
A: Yes! Add images to the `images/` folder and reference them in `index.html`.

**Q: How do emails get sent?**
A: Brevo stores submissions in the list connected to the form. Configure confirmation emails and notifications in your Brevo account.

**Q: What if I need more sections?**
A: Copy one of the existing sections in `index.html` and customize it!
